# Phase 0: 샘플과 시연 환경

현재 상태:
- 1차 개발/시연 환경: PC 또는 노트북에서 실행하는 로컬 웹 서비스
- 임베디드 최적화: Phase 2 이후 목표 보드가 정해지면 병행 검토
- 실제 YOLO/얼굴 임베딩 모델: Phase 2/3에서 연결

준비해야 할 샘플:
- 짧은 테스트 영상 2~3개
- 참조 인물 얼굴 사진 1장 이상
- 차량 번호판이 보이는 테스트 영상
- 캐릭터/이모지 asset

샘플 파일 배치:
- 영상: `samples/videos/`
- 참조 이미지: `samples/references/`
- QA 기록: `samples/qa-template.md`를 복사해서 사용

1차 시연 목표:
- 웹에서 영상과 참조 사진을 업로드한다.
- 서버가 작업 ID를 만든다.
- 상태 조회와 결과 다운로드가 동작한다.
- Phase 2부터 YOLO 기반 blur 처리 결과를 연결한다.
